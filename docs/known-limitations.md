# 当前限制与依赖维护

本公开版本优先复现已验证的 0.5.17 工作流，未借整理仓库大范围升级桌面运行时。

- 目标平台为 Windows x64；不承诺 macOS / Linux 的路径、编码器和便携包行为。
- OCR 需要人工校对，离线曲库快照可能落后于游戏更新。Potential 规则以程序支持的选项为准。
- 实时预览受本机解码性能影响，重要接点仍需短片验证。
- `npm ci` 首次下载 Electron 等资源可能受网络中断影响；恢复网络后重试 `npm ci` 或 `npm rebuild electron`。不要关闭 TLS 校验绕过下载问题。
- 依赖仍固定为 Electron 33.3.0、ONNX Runtime Node 1.20.1 与 esbuild 0.21.5。发布整理时 npm 报告依赖安全告警；请运行 `npm audit` 查看当前详情。固定旧版并不等于已修复安全问题，后续维护应单独升级依赖并重新验证 OCR、预览和导出。不要直接用 `npm audit fix --force` 替代兼容性验证。
- 公开仓库不含 Apple 图像或 FFmpeg 二进制。运行资源需在本地准备，公共 CI 有意跳过 Apple 图像完整性测试；严格本机验证使用 `npm run verify`。

遇到问题时，可提供版本、Windows 版本、重现步骤、错误文本和经脱敏的工程。不要提交私人素材、完整 OCR 原图、访问令牌或电脑个人目录。
