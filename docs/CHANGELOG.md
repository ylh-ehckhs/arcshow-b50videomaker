# 版本说明

## 0.5.17

公开源码对应已完成整部影片导出和人工观看确认的程序版本。

- 短评编辑支持中文右键菜单、纯文字 / HTML-only 剪贴板兼容、图片粘贴反馈和 Apple 效果区。
- 原始 Unicode 保存，支持输入法、换行、肤色、组合表情和整字素截断。
- 保留独立黑底、图片深度、逐曲背景与文字、响度统一、动画原声及连续接点。
- 整理公开目录：无旧便携包、私人验证素材、分表截图与电脑绝对路径。
- 增加无媒体完整工程、精确裁剪 / 顺序表、素材清单、逐步教程和开发指南。
- 测试固定数据移至 `tests/fixtures/`，资源准备不再依赖私人目录。

## 既有功能

0.5 系列逐步完成无片头剪辑、逐段裁剪、动画 / 双难度 / remix 排序、共同音源与离线校准、独立原声 0 秒切换、静音黑场、响度统一、0.3 秒接点模糊、0.5 秒总览翻页模糊、模糊边缘修复、预览预加载与音频预调度、波形选区修复，以及播放期间滚动编辑区保持显示。

历史调试脚本、旧便携版和含私人素材的验证影片不在公开树内。当前操作以根 README 和完整示例为准。
