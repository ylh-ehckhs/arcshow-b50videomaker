# 素材需求清单

本目录不附带媒体，也不提供下载链接。自行准备有权使用的对应内容，再按以下相对路径放到 `example.arcshow` 旁。扩展名也需一致，或在程序中重新选择文件。

“音视频至少覆盖至”指原文件时间点，不是影片展示时长。末曲包含总览延续，因此要求比单曲画面结束更长。建议保留完整原片，避免只裁出所列范围。

同曲 FTR / BYD 必须对应各自难度；解锁动画应使用自己的文件。背景建议 16:9、1920×1080 或更高，选相似色调即可，主题不会自动把图片变成相同图案。换素材版本后要重新确认音画位置。

## 不需要准备的内容

示例使用录像原声和动画原声，没有额外全局背景音乐，也没有角色立绘。本曲图片字段和布局图片列表为空；独立黑底由程序绘制。原始 OCR 分表没有公开，直接打开工程或导入 `scores.json` / `scores.csv` 即可继续学习。

## 重新关联的方法

选择“成绩与剪辑”中的单曲或动画卡，使用对应的“谱面录像” / “动画视频”按钮选择文件。逐曲背景在同一编辑区，全局背景在“影片设置”。若一次扫描自己的素材目录，请在自动匹配后逐一检查难度和素材类型。自动匹配只负责候选关联，不保证两个不同上传版本的时间位置相同。
