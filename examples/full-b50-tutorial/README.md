# 完整 B50 制作示例：从成绩到成片

这是用 **0.5.17** 完成的一次真实工作流程的公开教学副本。原片已导出并人工观看确认。这里保留最终成绩、影片顺序、所有选段、动画位置、背景分配和布局；玩家信息、短评改成示例内容，媒体和 OCR 截图没有公开。

> 可以从头跟做，也可以打开 `example.arcshow` 查看完成状态。后者提示素材缺失属于正常情况，请按 `assets-required.md` 准备 / 关联自己的文件。**不要直接覆盖自己已调好的工程。** 秒数对应参考录像的文件时间，自己的录像开头不同就要重新定位。

## 文件与两种跟做方式

| 文件 | 用法 |
| --- | --- |
| `example.arcshow` | 已完成的 50 曲 + 动画 + 总览工程；关联素材后查看 |
| `scores.json` / `scores.csv` | 从成绩开始跟做，任选一种导入，不要重复导入两份 |
| `clip-settings.csv` | 56 张内容卡的逐段参数，普通曲目与特殊组都列出 |
| `timeline.csv` | 含黑场与总览的影片时间表，便于核对总时长与录制 |
| `assets-required.md` / `.json` | 64 个媒体引用、用途和所需覆盖范围 |

### 方式 A：查看完成工程

1. 复制整个示例目录作为自己的工作副本。
2. 按素材清单创建 `assets/gameplay`、`assets/unlocks`、`assets/backgrounds`，放入自己的素材；也可先打开工程再逐项选文件。
3. 用“打开工程”选择 `example.arcshow`，另存为自己的工程。
4. 在“成绩与剪辑”检查素材和时间，在“视频布局”观察布局；重要接点做局部预览 / 短片确认。
5. 每次保存都保留自己的修改。普通保存可能将媒体路径写为已解析的绝对路径，搬电脑后应重新关联。

### 方式 B：从成绩开始完整跟做

按下面第 1～12 步操作。开始前准备足够磁盘空间、谱面视频和解锁动画，使用当前版本并完成运行资源校验。

## 第 1 步：建立与保存工程

1. 新建工程，先另存为一个 `.arcshow` 文件。
2. 在“影片设置”填写工程名、玩家名和日期，账号 Potential 可选填；它不会从成绩均值自动推算。
3. 分表数量选择 50。示例采用 `v7` 规则、1920×1080、60 FPS、CRF 18、自动编码。第一次测试可先做短片，确认后再出全片。
4. 先保存一次，之后每完成一个分组再保存，方便回退。

**检查点：** 工程名称正确，当前是新副本，没有把已完成的私人工程重置。

## 第 2 步：导入成绩并校对

没有公开原图时，点击“导入 JSON / CSV”，选择这里的 `scores.json` 或 `scores.csv`。如果使用自己的长分表，点击“长分表 OCR”，在导入界面选择或拖入图片。

1. 先看预览里的网格是否真的覆盖 50 张卡。默认是 5 列×10 行、上边界 24%，只适合对应版式，不是所有分表通用参数。
2. 识别后逐卡对照截图：曲名、PST / PRS / FTR / BYD / ETR / INS、定数、分数、通关状态、FAR 和 LOST。
3. FAR / LOST 的空值是未知，不能随手填 0；有错误就按原图手动更正。
4. Potential 警告先核对分数、定数、通关状态和规则。确认可信图中值后，可“使用图中值”或填写覆盖值；“恢复自动”清除覆盖。
5. 特别看假名 / 特殊字符、同曲不同难度和相邻卡是否串入。历史流程中曾出现 World Ender 与 Undying Macula 串卡，因此不要只核对卡片总数。
6. 全部核对后确认导入，另存工程。

**检查点：** 50 条成绩都已人工确认，没有未解释的数据警告。直接导入示例成绩可以跳过 OCR，但仍应了解核对过程。

## 第 3 步：扫描与匹配素材

1. 在“成绩与剪辑”点击“扫描素材目录”，选择自己的谱面录像文件夹。
2. 点击“自动匹配空白素材”。
3. 检查所有卡片，尤其 Testify FTR / BYD、Xterfusion ETR、Arcana Eden FTR / BYD、Lament Rain。
4. 对未匹配的卡片，选中后点击“谱面录像”手动指定。若扫描结果是 44 首，表示还有 6 首需要补全，并非已全部成功。
5. 检查 Stasis：曾有解锁动画被自动选作谱面，应替换为正确 FTR 谱面视频。解锁动画稍后通过“插入动画”单独加入。
6. 独立片段配乐选择“仅录像原声”。示例不用额外全局背景音乐。

**检查点：** 50 张单曲卡都有正确难度的谱面画面，原声正常。不要用解锁动画凑够匹配数量。

## 第 4 步：设置普通段落的节奏

展开“全片时间与声音”，示例的最终值如下：

| 设置 | 数值 |
| --- | --- |
| 独立片段之间留白 | 1 秒 |
| 画面淡出＋淡入 | 共 1 秒 |
| 音乐淡出／淡入 | 每侧 0.7 秒 |
| 谱面切换模糊 | 共 0.3 秒 |
| 整体音量 | 0.8 |
| 统一配乐响度 | 开启 |
| 默认单曲时长 | 20 秒 |

1. 可以在尚未选段前设默认 20 秒。已经逐曲调好的工程不要点击“应用默认时长到全部曲目”。
2. 普通曲目保留自动转场，上一段在自身尾部淡出，1 秒黑屏静音后下一段淡入。
3. 连续的动画 / 双难度 / remix 接点稍后逐项覆盖为直切和音乐淡化 0，不能只改全片默认。

**检查点：** 普通曲目间有反应时间，连接组内部没有黑场。留白额外增加影片长度，模糊不增加长度。

## 第 5 步：调整顺序和每曲取用范围

1. 拖动下方顺序卡片，先大致按 Best 倒序，再把相同曲目不同难度、remix 放在一起。卡片上的 Best 排名不会因拖动变化。
2. 选中单曲，在上方原片预览找一段完整乐句。输入“视频开始时间”和“视频结束时间”；这两个数都是原文件秒数。
3. 点击原片播放器找画面，使用“从当前画面开始” / “到当前画面结束”，或直接输入数字。
4. 回车或离开框提交。↑↓ 为 0.1 秒、Shift + ↑↓ 为 1 秒、Alt + ↑↓ 为 0.001 秒；无需反复点击按钮。
5. 用“循环选区”试听起止，结束尽量落在副歌 / 乐句结束或自然尾音，避免按机械 20 秒截断。再点循环按钮停止。
6. 普通曲目多在 17～27 秒，重要曲目可延长。全部最终范围见文末表和 `clip-settings.csv`。

**检查点：** 不只是画面正确，声音也从合适拍点开始和结束。更换原文件后重新检查秒数。

## 第 6 步：动画和连续组通用操作

每组采用同样的方法，再填写后面的具体时间：

1. 选中附近卡片，点击“＋ 插入动画”，选择本地动画视频。
2. 在顺序区把动画拖到目标单曲之前；不同难度拖成相邻，确认没有别的歌曲插在中间。
3. 在动画卡填写开始和结束时间，“动画配乐”选择“使用动画原声”，动画原声音量 1。
4. 选中动画后面的谱面卡，在“与上一段的画面转场”选择“直接切换（0 秒）”。
5. 把该谱面卡的“音乐淡出／淡入（每侧秒数）”填 `0`。同组下一难度也做同样设置。留空是继承全片 0.7，并非 0。
6. 本次完成工程使用各段自己的原声，**没有建立共同配乐组**。这保留动画本身的剪辑节奏，避免把谱面开头的音乐突然借到动画后半段。
7. 选择接点的卡片，点击“试听接点”，并从组第一张卡开始连续预览。0.3 秒模糊适用于动画接谱面和连续歌曲，音乐无需跟着模糊淡化。
8. 找到满意位置后保存。不同录像文件的音乐偏移不同，表中的秒数只用于同版本参考；最终仍听两边拍点。

如果另一个工程确实要一条共同音乐贯穿，使用“与前一段连接配乐”，选择共同音源，再自动对齐 / 人工微调偏移并确认。连接状态未确认会阻止导出。不要为了得到 0 秒画面切换而强行连接音频。

## 第 7 步：选择背景与组件布局

1. 在“影片设置”选印象配色和白昼 / 暮光。示例为“光”与“白昼”。
2. 选择全局背景，示例用一个浅色 16:9 背景；空白的本曲背景继承它。
3. 对特殊组在“成绩与剪辑”选择“本曲背景”。背景继承为本曲 → 全局 → 主题底色，不把曲绘作为候补。
4. 参考工程使用 8 个不同背景引用。下面列出本曲覆盖；未列出的歌曲继承全局。

| 曲目 | 背景相对路径 |

| Libertas BYD | `assets/backgrounds/background-04.jpg` |
| Singularity FTR | `assets/backgrounds/background-04.jpg` |

5. 打开“视频布局”，单曲画布只使用谱面录像。拖动曲名、视频、分数、Potential、评级、难度、排名和短评；可直接输入坐标和字号。
6. 难度与排名默认字重 600。排名为 `#50` 样式。难度标签可选“跟随难度”，采用 PST 蓝 / PRS 绿 / FTR 深紫 / BYD 红 / ETR 浅紫 / INS 深蓝，或切回印象配色。
7. 单曲默认两块独立黑底、总览默认一块，调整它们自己的宽高、位置和不透明度，避免每个文字框叠黑底。
8. 想叠自选图，点击“添加图片”；图层深度越大越靠前，2 及以上可覆盖文字。本例没有图片组件，也没有角色立绘。
9. 某曲背景颜色不适合全局字色时，在“本曲文字”只改必要的颜色 / 阴影。空白属性继续继承，不要把所有值重复填一遍。

**检查点：** 单曲和总览分别检查；小字在亮暗背景都清晰，文字不被自己的图片盖住。

## 第 8 步：逐曲短评

1. 在成绩列表右键“编辑”，或选中卡片点击“编辑成绩”。
2. 在短评文字输入区输入或粘贴 Unicode 表情，例：😡😭🤓😰🤔。该区的 Windows 外观不代表成片外观。
3. 看下方“显示效果 · Apple”；已准备本地资源时，它与成片使用同一图形。
4. 确定保存，再选下一曲。取消编辑应留在原列表位置，不改变成绩。
5. 在视频布局确认“短评”组件可见，实际场景中检查换行是否放得下。

公开工程的 50 条短评均为替换后的示例，请改成自己的内容。复制截图不是复制 emoji 字符。

## 第 9 步：末曲和结尾总览

1. 将 Inverted World ETR 放到最后，本例前面接它的解锁动画。
2. 谱面视频开始 40.26 秒，画面结束 117.55 秒，展示约 77.29 秒。
3. 选“结尾总览”，每页 4 秒，50 首共 5 页，总计 20 秒。
4. 总览排列选择“逆向：#50 → #1（从低到高）”，翻页模糊 0.5 秒。
5. 进入总览设为直接切换，音乐淡化 0。末曲原声继续覆盖五页，不重新开一条音轨。
6. 最后同一音源实际取到约 137.543333 秒；它包括帧边界规划后的末曲和总览。素材需要覆盖到那里，清单已计算这段余量。
7. 先看第一页，再连续看到第五页结束，确认自然尾音或原素材中的预期静音。参考工程的尾部留白已经人工确认，无需为了“听起来刚好结束”截掉原曲尾部。

**通用计算：** 最后画面结束时间 ≈ 希望音乐停止的原音源时间 − 总览总时长。换曲、换总览页数或时长后重新计算并试听，模糊不额外占时。

## 第 10 步：先试听特殊接点，再做短片

1. 在顺序区选某组第一张卡，从当前卡连续预览。
2. 逐个“试听接点”，检查没有非预期黑场、重复回闪和音量凹陷。
3. 第一次预览需分析响度和准备音轨；慢机器上的解码卡顿不应只靠实时预览判断最终成片。
4. 使用单段 / 局部导出先检查重要组；完整组若无法在一次局部导出中覆盖，可复制一个临时工程，仅保留该组再导出，原工程不要修改。
5. 播放导出的 MP4，听动画 → FTR → BYD 和 remix 节拍；模糊应短暂而没有四周黑框。
6. 若听到接点音量下降，先看进入下一张卡的音乐淡化是否真的为 0，再检查素材本身；别为了消除淡化重新拖乱已对齐的视频。

## 第 11 步：全片导出

1. 保存工程，再打开“导出”。
2. 阅读所有预检：无缺失文件、无音视频越界、无未确认音画对应、无未解释的成绩问题。
3. 确认 1920×1080 / 60 FPS / CRF 18 和目标磁盘可用空间；临时合成也需要空间。
4. 选择自己的输出位置开始导出，等待完成，不要移动或改名被引用素材。
5. 检查最终总时长约 **23 分 53.867 秒**。替换素材但沿用同一工程参数时，总时长应基本一致。
6. 看全片首尾、所有特殊接点、背景变更、短评、五页总览与最后尾音，再决定上传到视频平台。

本仓库没有成片附件，不会自动把你的媒体上传 GitHub 或视频平台。

## 第 12 步：保存可继续修改的工程
